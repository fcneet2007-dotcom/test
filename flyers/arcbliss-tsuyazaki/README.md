## 出典と、どちらを採ったか

2つの資料を突き合わせている。

- **アークブリス津屋崎.pdf**（エイブル新宮店／101号室／広告有効期限 2026-09-23）
- **ＡＲＣＢＬＩＳＳ津屋崎 消込表.xlsx**（九州広島管理事業部／広告有効期限 2026-08-15）

| 項目 | 採用 | 理由 |
| --- | --- | --- |
| 101号室の賃料 | 69,000円（新宮店PDF） | 消込表は72,000円。PDFのほうが新しく、新宮店の現在の募集条件 |
| 102・103・201〜203の賃料 | 消込表の値 | 他に出典がない。**8/15時点のため要確認** |
| 申込状況 | 消込表 | 201・202に「申」の丸印。残り4戸（101・102・103・203） |
| 完成/入居 | 完成済（PDF：2026-07-09完成） | 消込表は「建築中（8/1入居開始予定）」で、作成時点が古い |
| 月額保険料等 | 1,050円（PDF） | 消込表は火災保険 月額1,200円 |
| 短期解約違約金・退去時清掃代 | 消込表 | PDFに記載がない特約。注記に追加した |
| 2階の間取り・面積・WIC | 消込表 | 2LDK・52.11㎡・ウォークインクローゼット付 |

消込表の業者間条件（手数料負担・分配、広告料、元付連絡先）はチラシに載せていない。

## 差し替え・確認が必要な箇所

- **プレゼントの中身** — 現在は「中身は、ご来店してのお楽しみ。」と伏せている。
  商品や金額を告知する場合は見出し直下のこの1行を差し替える。
- **店長写真** — 目を閉じた居酒屋での1枚をトリミングして使っている。エイブルの店名を
  出す配布物なので、ご本人の了承と、この見え方でよいかを配布前に確認すること。
- **102・103・201〜203の賃料** — 8/15時点の消込表の値。101号室が72,000円→69,000円に
  下がっているため、他号室も改定されていないか確認する。
- **空室状況の日付** — 「2026年9月16日現在」。配布前に消込表と突き合わせて更新する。
